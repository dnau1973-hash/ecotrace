Documentation Technique et Utilisateur : EcoTrace 🍃

Projet : Moteur de qualification RSE, calcul d'empreinte carbone Scope 3 et analyse du risque
Version : 1.4.1 (Août 2026)
Environnement : Docker / ZimaOS / LAMP (PHP 8.2, Apache, MySQL 8.0)
Auteur : David NAU

1. Présentation Générale

EcoTrace 🍃 est une application web interne conçue pour automatiser le rapprochement d'entités (fournisseurs, clients, partenaires), qualifier les bases de données et estimer l'empreinte carbone (Scope 3) ainsi que le niveau de risque financier de la chaîne de valeur.

  • Importation de fichiers CSV (Nom seul, ou enrichi avec Montants € et Poids kg).
  • Interrogation d'API officielles et privées (Gouv.fr, Pappers, Societe.com, OpenData BODACC).
  • Calcul automatique du kilométrage routier (OSRM) et géocodage mondial de secours (OpenStreetMap).
  • Détection des labels RSE : Secteur Alimentaire, ESS (Économie Sociale et Solidaire), Société à Mission.
  • Calculateur d'émissions de CO2 estimées (Ratios monétaires ADEME par NAF + Fret Tonnes-Kilomètres).
  • Module d'analyse du risque financier avec modale interactive d'affichage des annonces légales BODACC.
  • Dashboard RSE interactif avec cartes mondiales (Leaflet) et graphiques analytiques (Chart.js).

2. Configuration et Clés API (.env)

L'application est entièrement paramétrable via son assistant graphique ou le bouton ⚙️ Éditer la configuration du menu d'actions :

  • DB_HOST, DB_NAME, DB_USER, DB_PASS : Connexion MySQL.
  • ADMIN_USER, ADMIN_PASS : Identifiants administrateur EcoTrace.
  • ORIGIN_LAT, ORIGIN_LON : Coordonnées GPS du siège/entrepôt d'origine.
  • PAPPERS_API_KEY : (Optionnel) Clé API Pappers pour la recherche par enseigne.
  • SOCIETE_API_KEY : (Optionnel) Clé API Societe.com / SocieteInfo.

3. Analyse du Risque et Modale BODACC

Lors de chaque qualification, EcoTrace scanne la base du BODACC. Si l'entreprise est en Redressement, Liquidation, Sauvegarde ou En difficulté, un badge d'avertissement de couleur s'affiche à côté de son nom.

En cliquant directement sur ce badge de santé juridique, une fenêtre modale s'ouvre et affiche le texte officiel de la dernière publication au journal officiel (Tribunal, Date, Motif) ainsi que des liens d'accès direct aux fiches officielles BODACC.fr et Societe.com.

4. Méthodologie de Calcul Carbone (Scope 3)

La fonction d'estimation de l'empreinte carbone d'EcoTrace repose sur la méthodologie macro-économique recommandée par l'ADEME (Agence de la transition écologique) pour l'évaluation du Scope 3. Le calcul final additionne deux approches :

A. L'approche physique : Le Fret (Transport logistique)

Si un poids (en kg) est renseigné (soit par import CSV, soit manuellement), EcoTrace croise cette donnée avec la distance routière :

  • L'unité de mesure (Tonne-Kilomètre) : L'application convertit le poids en tonnes, puis le multiplie par la distance pour obtenir les tkm.
  • Le facteur d'émission : EcoTrace applique un ratio routier moyen de 0,1 kg de CO2 par tkm (représentant un poids lourd standard).

B. L'approche monétaire : Les Achats

Si un montant (en euros) est renseigné, l'application utilise les Facteurs d'Émissions Monétaires (FEM). EcoTrace analyse les 2 premiers chiffres du Code NAF officiel de l'entreprise pour affecter un ratio sectoriel de CO2 par euro dépensé :

  • Transport lourd (NAF 49 à 52) : 0,80 kg de CO2 / € (Impact élevé lié aux carburants).
  • Alimentaire & Restauration (NAF 10, 11, 56) : 0,45 kg de CO2 / € (Impact fort lié à l'agriculture/transformation).
  • Services, Numérique, Immobilier (NAF 61 à 63, 69 à 71) : 0,05 kg de CO2 / € (Impact faible : prestations intellectuelles).
  • Par défaut (Autres secteurs) : 0,20 kg de CO2 / € (Moyenne nationale générique).
💡 Validation de la méthode :
Bien qu'il s'agisse d'une estimation ("par proxy" sectoriel) et non d'une Analyse de Cycle de Vie (ACV) au gramme près, cette méthodologie est totalement validée par les normes internationales (GHG Protocol). Elle permet de cartographier de manière fiable les principaux postes d'émissions de la chaîne d'approvisionnement.

5. Modèle de Données et Sauvegardes Dump SQL

Deux tables principales constituent le cœur de la base : sources_csv et api_resultats.

  • Sauvegarde (Export SQL) : Le menu d'actions permet de générer à tout moment un dump SQL complet avec la clause CREATE TABLE IF NOT EXISTS.
  • Restauration (Import SQL) : Le bouton "📂 Importer Dump (SQL)" permet d'injecter un fichier .sql pour restaurer instantanément l'état de l'application sur n'importe quel serveur.

6. Guide d'Installation

EcoTrace 🍃 est conçu pour être auto-suffisant. L'application déclenche automatiquement un assistant de configuration et génère ses tables de base de données au premier lancement.

A. Installation via Docker & ZimaOS (Recommandée)

💡 Installation en 1 clic sur ZimaOS / CasaOS :
Copiez-collez le code ci-dessous dans le module "Custom Install" de ZimaOS ou dans un fichier docker-compose.yml classique. 
version: '3.8'

services:
  web:
    image: php:8.2-apache
    ports:
      - "8080:80"
    volumes:
      - ./:/var/www/html
    depends_on:
      - db
    # Installation à la volée des extensions PHP requises
    command: >
      bash -c "docker-php-ext-install pdo pdo_mysql && apache2-foreground"

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: VotreMotDePasseSecret!
      MYSQL_DATABASE: ecotrace
    volumes:
      - ecotrace_db_data:/var/lib/mysql

volumes:
  ecotrace_db_data:

B. Installation sur un serveur Apache standard (LAMP / WAMP / XAMPP)

  1. Prérequis : Un serveur web avec Apache, PHP 8.1 ou supérieur (avec les extensions pdo_mysql et curl activées), et un serveur MySQL ou MariaDB fonctionnel.
  2. Déploiement : Copiez tous les fichiers du projet (index.php, doc.html, licence.html, presentation.html, historique.html) dans le répertoire public de votre serveur web (ex: /var/www/html/ecotrace).
  3. Permissions : Assurez-vous que l'utilisateur exécutant Apache (souvent www-data sous Linux) possède les droits d'écriture sur ce dossier. L'application a besoin de ce droit pour créer le fichier .env lors de la configuration initiale.
  4. Lancement : Ouvrez votre navigateur et accédez à l'URL correspondante (ex: http://localhost/ecotrace/). L'assistant de configuration s'affichera pour relier la base de données (si le fichier .env n'est pas encore créé).
