Documentation Technique et Utilisateur : EcoTrace 🍃

Projet : Moteur de qualification RSE, calcul d'empreinte carbone Scope 3 et analyse du risque
Version : 1.6.1 (Août 2026)
Environnement : Docker / ZimaOS / LAMP (PHP 8.2, Apache, MySQL 8.0)
Auteur : David NAU

1. Présentation Générale

EcoTrace 🍃 est une application web interne conçue pour automatiser le rapprochement d'entités (fournisseurs, clients, partenaires), qualifier les bases de données et estimer l'empreinte carbone (Scope 3) ainsi que le niveau de risque financier de la chaîne de valeur.

  • Importation de fichiers CSV (Nom seul, ou enrichi avec Montants € et Poids kg).
  • Interrogation d'API officielles et privées (Gouv.fr, Pappers, Societe.com, OpenData BODACC).
  • Calcul automatique du kilométrage routier (OSRM) et géocodage mondial de secours (OpenStreetMap).
  • Détection des labels RSE : Secteur Alimentaire, ESS (Économie Sociale et Solidaire), Société à Mission.
  • Calculateur d'émissions de CO2 estimées (Ratios monétaires ADEME par grandes familles NAF + Fret Tonnes-Kilomètres).
  • Module d'analyse du risque financier avec modale interactive d'affichage des annonces légales BODACC.
  • Outils de traitement de masse (Surlignage de SIREN connus via CSV) et mise à jour transparente de l'interface.
  • Mise à jour "Over-The-Air" (Auto-Updater) via synchronisation avec un dépôt GitHub.
  • Dashboard RSE interactif avec cartes mondiales (Leaflet) et graphiques analytiques (Chart.js).

2. Configuration et Clés API (.env)

L'application est entièrement paramétrable via son assistant graphique ou le bouton ⚙️ Éditer la configuration du menu d'actions :

  • DB_HOST, DB_NAME, DB_USER, DB_PASS : Connexion MySQL.
  • ADMIN_USER, ADMIN_PASS : Identifiants administrateur EcoTrace.
  • ORIGIN_LAT, ORIGIN_LON : Coordonnées GPS du siège/entrepôt d'origine.
  • PAPPERS_API_KEY : (Optionnel) Clé API Pappers pour la recherche par enseigne.
  • SOCIETE_API_KEY : (Optionnel) Clé API Societe.com / SocieteInfo.
  • GITHUB_REPO : URL du dépôt pour les mises à jour automatiques (voir Section 7).

3. Analyse du Risque et Modale BODACC

Lors de chaque qualification, EcoTrace scanne la base du BODACC. Si l'entreprise est en Redressement, Liquidation, Sauvegarde ou En difficulté, un badge d'avertissement de couleur s'affiche à côté de son nom.

En cliquant directement sur ce badge de santé juridique, une fenêtre modale s'ouvre et affiche le texte officiel de la dernière publication au journal officiel (Tribunal, Date, Motif) ainsi que des liens d'accès direct aux fiches officielles BODACC.fr et Societe.com.

4. Méthodologie de Calcul Carbone (Scope 3)

La fonction d'estimation de l'empreinte carbone d'EcoTrace repose sur la méthodologie macro-économique recommandée par l'ADEME (Agence de la transition écologique) pour l'évaluation du Scope 3. Le calcul final additionne deux approches :

A. L'approche physique : Le Fret (Transport logistique)

Si un poids (en kg) est renseigné (soit par import CSV, soit manuellement), EcoTrace croise cette donnée avec la distance routière :

  • L'unité de mesure (Tonne-Kilomètre) : L'application convertit le poids en tonnes, puis le multiplie par la distance pour obtenir les tkm.
  • Le facteur d'émission : EcoTrace applique un ratio routier moyen de 0,1 kg de CO2 par tkm (représentant un poids lourd standard).

B. L'approche monétaire : Les Achats

Si un montant (en euros) est renseigné, l'application utilise les Facteurs d'Émissions Monétaires (FEM). EcoTrace analyse les 2 premiers chiffres du Code NAF officiel de l'entreprise pour affecter un ratio sectoriel de CO2 par euro dépensé :

  • Transport lourd (NAF 49 à 52) : 0,80 kg de CO2 / € (Impact élevé lié aux carburants).
  • Alimentaire & Restauration (NAF 10, 11, 56) : 0,45 kg de CO2 / € (Impact fort lié à l'agriculture/transformation).
  • Services, Numérique, Immobilier (NAF 61 à 63, 69 à 71) : 0,05 kg de CO2 / € (Impact faible : prestations intellectuelles).
  • Par défaut (Autres secteurs) : 0,20 kg de CO2 / € (Moyenne nationale générique).
💡 Validation de la méthode :
Bien qu'il s'agisse d'une estimation ("par proxy" sectoriel) et non d'une Analyse de Cycle de Vie (ACV) au gramme près, cette méthodologie est totalement validée par les normes internationales (GHG Protocol). Elle permet de cartographier de manière fiable les principaux postes d'émissions de la chaîne d'approvisionnement.

5. Modèle de Données et Sauvegardes Dump SQL

Deux tables principales constituent le cœur de la base : sources_csv et api_resultats.

  • Sauvegarde (Export SQL) : Le menu d'actions permet de générer à tout moment un dump SQL complet avec la clause CREATE TABLE IF NOT EXISTS.
  • Restauration (Import SQL) : Le bouton "📂 Importer Dump (SQL)" permet d'injecter un fichier .sql pour restaurer instantanément l'état de l'application sur n'importe quel serveur.

6. Guide d'Installation

EcoTrace 🍃 est conçu pour être auto-suffisant. L'application déclenche automatiquement un assistant de configuration et génère ses tables de base de données au premier lancement.

A. Installation via Docker & ZimaOS (Recommandée)

💡 Installation en 1 clic sur ZimaOS / CasaOS :
Copiez-collez le code ci-dessous dans le module "Custom Install" de ZimaOS ou dans un fichier docker-compose.yml classique. 
name: ecotrace
services:
  web:
    image: php:8.2-apache
    container_name: ecotrace_web
    restart: always
    ports:
      - "8083:80"
    volumes:
      - /DATA/AppData/ecotrace:/var/www/html
    command: >
      /bin/bash -c "apt-get update &&
      apt-get install -y git &&
      docker-php-ext-install pdo pdo_mysql &&
      git config --system --add safe.directory '*' &&
      chown -R www-data:www-data /var/www/html &&
      apache2-foreground"
    depends_on:
      - db
  
  db:
    image: mysql:8.0
    container_name: ecotrace_db
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: "VotreMotDePasseSecret!"
      MYSQL_DATABASE: "ecotrace"
    volumes:
      - ecotrace_db_data:/var/lib/mysql

volumes:
  ecotrace_db_data:
    driver: local

B. Installation sur un serveur Apache standard (LAMP / WAMP / XAMPP)

  1. Prérequis : Un serveur web avec Apache, PHP 8.1 ou supérieur (avec les extensions pdo_mysql et curl activées), le paquet git installé sur la machine hôte, et un serveur MySQL ou MariaDB fonctionnel.
  2. Déploiement : Copiez tous les fichiers du projet dans le répertoire public de votre serveur web (ex: /var/www/html/ecotrace).
  3. Permissions : Assurez-vous que l'utilisateur exécutant Apache possède les droits d'écriture sur ce dossier.
  4. Lancement : Ouvrez votre navigateur et accédez à l'URL correspondante. L'assistant de configuration s'affichera pour paramétrer le fichier .env.

7. Mises à jour automatiques et Token GitHub

EcoTrace intègre un système "Auto-Updater" qui lui permet de vérifier la disponibilité d'une nouvelle version sur un dépôt GitHub et de s'auto-mettre à jour en un clic (en utilisant la commande git reset --hard). Étant donné que le dépôt est privé, il est nécessaire de générer un Personal Access Token (PAT) sur GitHub pour autoriser EcoTrace à s'y connecter en silence.

⚠️ Règle de Sécurité Absolue :
Le jeton secret ne doit jamais être écrit dans le code source de l'application (sous peine d'être bloqué par la sécurité "Push Protection" de GitHub). Il doit être inséré uniquement via l'interface de configuration d'EcoTrace, qui le stockera dans le fichier local caché .env (ignoré par Git grâce au fichier .gitignore).

Étape 1 : Générer le Jeton (Token) sur GitHub

  1. Connectez-vous à votre compte sur GitHub.
  2. Cliquez sur votre photo de profil (en haut à droite), puis allez dans Settings (Paramètres).
  3. Dans le menu de gauche, descendez tout en bas et cliquez sur Developer settings.
  4. Déroulez la section Personal access tokens et choisissez Tokens (classic).
  5. Cliquez sur Generate new token (classic).
  6. Remplissez les informations :
    • Note : Auto-Updater EcoTrace
    • Expiration : No expiration (Recommandé pour ne pas casser l'auto-updater).
    • Scopes : Cochez uniquement la case repo (permet de lire votre dépôt privé).
  7. Cliquez sur le bouton vert Generate token tout en bas.
  8. Copiez immédiatement la chaîne de caractères verte (ex: ghp_A1b2C3d4...). GitHub ne la réaffichera plus !

Étape 2 : Configurer le lien dans EcoTrace

L'URL standard de votre dépôt ressemble à :
https://github.com/votre-compte/ecotrace.git

Pour y inclure l'autorisation silencieuse, ajoutez votre jeton suivi d'un @ juste avant github.com :
https://ghp_A1b2C3d4...@github.com/votre-compte/ecotrace.git

  1. Ouvrez EcoTrace, ouvrez le menu ⚙️ Actions ▾ et cliquez sur ⚙️ Éditer la configuration.
  2. Collez cette URL modifiée dans le champ Lien dépôt GitHub (Auto-Updater).
  3. Cliquez sur 💾 Enregistrer et Continuer.

Désormais, EcoTrace vérifiera automatiquement la disponibilité des mises à jour (un badge clignotant rouge "Mise à jour disponible !" s'affichera à côté du numéro de version si nécessaire).

8. Outils de Rapprochement et Ajout Manuel

Pour fluidifier le travail de l'utilisateur, plusieurs fonctionnalités ergonomiques ont été intégrées dans les onglets de Rapprochement et d'Ajout Manuel :

A. Maintien de la position de navigation (Scroll)

Lorsque vous traitez une longue liste d'entreprises en attente (clic sur un bouton API, validation d'un candidat, suppression), l'application sauvegarde instantanément votre position de défilement (scroll) en mémoire. Au rechargement de la page, vous êtes replacé exactement au même endroit, évitant ainsi d'avoir à redescendre toute la liste.

B. Suppression rapide d'une requête (🗑️)

Dans l'onglet "Rapprochement", un bouton rouge Corbeille (🗑️) est disponible à côté des boutons d'API pour chaque entité. Il permet d'écarter et de supprimer définitivement de la base de données un nom jugé non pertinent (ou mal importé), sans avoir besoin de passer par un état "Introuvable".

C. Surlignage via SIREN (Fichier CSV)

Ce bouton situé dans le menu ⚙️ Actions ▾ permet d'importer rapidement un fichier CSV (ou un fichier texte) contenant une liste de numéros SIREN avec lesquels vous avez déjà travaillé, ou qui sont déjà qualifiés par ailleurs. L'application scanne instantanément ce fichier et effectue les opérations suivantes :

  • Elle identifie tous les numéros à 9 chiffres.
  • Elle compare ces numéros avec les entreprises proposées dans l'onglet "Rapprochement".
  • Elle surligne les correspondances avec un fond vert pastel, ce qui permet à l'utilisateur de savoir visuellement quel candidat choisir.
  • Elle enregistre cette "connaissance" dans la base de données de manière persistante.

D. Contournement de l'API (Saisie manuelle directe)

Dans l'onglet "➕ Ajout Manuel", vous pouvez lancer une vérification via Gouv.fr pour vérifier la présence d'une entreprise avant de l'importer. Toutefois, si vous savez que l'entité n'est pas répertoriée (fournisseur étranger, association non déclarée...), vous pouvez utiliser le bouton ✏️ Saisie manuelle directe. Ce bouton permet de forcer l'affichage du formulaire et de créer l'entité dans la base d'EcoTrace sans interroger les serveurs de l'État.
