Historique des versions

Retrouvez ici la liste des modifications, corrections et nouveautés apportées à EcoTrace 🍃.

Version 1.6.3 Août 2026

  • Correction Import NAF (INSEE) : Mise en place d'un convertisseur d'encodage automatique (Windows-1252 vers UTF-8) pour traiter sans erreur les fichiers CSV officiels de l'INSEE comportant des accents français. Amélioration de la gestion des erreurs réseau et forçage de la création de la table avant l'importation.

Version 1.6.2 Août 2026

  • Nouveauté Dictionnaire NAF (INSEE) : Création d'une table dédiée en base de données pour héberger l'intégralité des codes NAF existants (732 sous-classes).
  • Optimisation Outil d'importation : Ajout d'une fonctionnalité dans le menu d'actions pour injecter à la volée le fichier CSV officiel de l'INSEE (insee.codenaf.csv).
  • Correction Précision des libellés : L'application affiche désormais le libellé exact au lieu de la grande famille générique si le code NAF est connu dans la nouvelle base.

Version 1.6.1 Août 2026

  • Nouveauté Surlignage persistant : Lors de l'import d'un fichier CSV de numéros SIREN, l'application sauvegarde désormais la correspondance directement dans la base de données. Les candidats "connus" resteront surlignés en vert de manière permanente, même après actualisation de la page.

Version 1.6.0 Août 2026

  • Nouveauté Outil de rapprochement : Ajout d'une fonctionnalité permettant d'importer une liste de SIREN (au format CSV). L'application scanne instantanément les candidats proposés dans l'onglet "Rapprochement" et surligne en vert pastel ceux dont le SIREN correspond au fichier, facilitant ainsi la prise de décision.

Version 1.5.41 Août 2026

  • Nouveauté Secteurs d'activité (NAF) : Intégration de la nomenclature complète des 88 grandes divisions d'activités de l'INSEE. L'application affiche désormais des libellés précis ("Transports terrestres", "Architecture et ingénierie"...) au lieu du simple message générique "Secteur d'activité".

Version 1.5.4 Août 2026

  • Optimisation Ergonomie de liste : L'application mémorise désormais votre position de défilement (scroll) lors du traitement ou de la suppression d'une entité. La page ne remonte plus tout en haut après un rechargement.
  • Nouveauté Onglet Rapprochement : Ajout d'un bouton de suppression rapide (🗑️) à côté des boutons de recherche d'API, pour écarter rapidement une entité inutile.
  • Optimisation Ajout Manuel : L'utilisateur peut désormais choisir de vérifier l'entreprise via l'API officielle, ou de "forcer" la saisie manuelle directement sans interroger les serveurs de l'État.

Version 1.5.3 Août 2026

  • Correction Sécurité GitHub : Retrait du jeton d'accès (Token) codé en dur dans les valeurs par défaut du fichier source pour respecter les standards de sécurité et éviter le blocage des commits par la "Push Protection" de GitHub. Le jeton doit être renseigné exclusivement via l'interface de configuration (.env).

Version 1.5.2 Août 2026

  • Correction Auto-Updater : Mise en place d'un système de sauvegarde en mémoire et de restauration instantanée du fichier .env lors des mises à jour GitHub. Cela empêche la suppression accidentelle des identifiants et l'apparition d'erreurs critiques de base de données.

Version 1.5.1 Août 2026

  • Optimisation Auto-Updater GitHub : Pré-intégration de l'URL sécurisée du dépôt GitHub (avec token d'accès) dans les paramètres par défaut de l'assistant d'installation pour un déploiement instantané.

Version 1.5.0 Août 2026

  • Nouveauté Auto-Updater GitHub : Intégration d'un système de mise à jour "Over-The-Air". L'application peut interroger un dépôt GitHub distant pour vérifier la présence d'une nouvelle version et télécharger les fichiers automatiquement après validation de l'utilisateur.
  • Optimisation Configuration Docker : Modification du port d'écoute externe sur le port 8083 et intégration native du paquet Git dans le conteneur.

Version 1.4.4 Août 2026

  • Optimisation Fenêtres Modales : Suppression du titre redondant dans la fenêtre d'affichage des documents (Documentation, Licence, Historique) afin de maximiser l'espace d'affichage de l'iframe.

Version 1.4.3 Août 2026

  • Optimisation Interface utilisateur : L'affichage de la Documentation, de la Licence, de la Présentation et de l'Historique s'effectue désormais dans des fenêtres modales intégrées (via iframe) plutôt que dans de nouveaux onglets, améliorant ainsi la fluidité de navigation sans quitter l'application.

Version 1.4.2 Août 2026

  • Optimisation Onglet Introuvables : Ajout d'un bouton de suppression rapide (🗑️) à côté du bouton "Gérer" pour permettre de nettoyer les requêtes échouées sans devoir les valider au préalable.
  • Correction Lien Societe.com : Correction de l'erreur 404 lors du clic sur le bouton "Fiche Societe.com" depuis la modale d'analyse du risque. Le lien utilise désormais le moteur de redirection officiel par SIREN.

Version 1.4.1 Août 2026

  • Correction Moteur de recherche Societe.com : Ajout du bouton manquant "Societe.com" dans les interfaces de rapprochement et de gestion des introuvables. L'application est désormais capable d'interroger directement cette API pour rechercher des entreprises.

Version 1.4.0 Août 2026

  • Nouveauté Analyse du risque interactive : Les badges de santé juridique sont désormais cliquables. L'ouverture d'une modale affiche le détail officiel de la dernière annonce légale (date, tribunal, détails) avec liens directs vers BODACC et Societe.com.
  • Nouveauté Support API Societe.com : Ajout du champ de clé API Societe.com dans l'éditeur de configuration `.env`.
  • Optimisation Mise à jour de la documentation et de la présentation : Actualisation globale de `doc.html` et `presentation.html` pour couvrir l'ensemble des fonctionnalités RSE, CO2 Scope 3, Dumps SQL et API.

Version 1.3.1 Août 2026

  • Optimisation Interface d'enrichissement : Réalignement esthétique du formulaire d'enrichissement des données (Montant et Poids). Les libellés ont désormais une largeur fixe pour garantir un alignement vertical parfait des champs de saisie.

Version 1.3.0 Août 2026

  • Nouveauté Éditeur de configuration : Ajout d'une option dans le menu pour modifier les paramètres vitaux de l'application (Identifiants de base de données, Mots de passe, Clé API Pappers, Coordonnées GPS) sans avoir à réinstaller le logiciel.
  • Nouveauté Enrichissement des données : Ajout d'un bouton "✏️ Enrichir" dans l'onglet des entités Validées. Il permet d'ajouter ou de modifier manuellement le montant des achats (€) ou le poids (kg) d'une entreprise pour affiner dynamiquement son estimation CO2.

Version 1.2.2 Août 2026

  • Correction Menu d'actions : Restauration des boutons de maintenance (Maj GPS, NAF, Alimentaire, Santé) et de l'option de réinstallation complète qui avaient disparu du menu déroulant.

Version 1.2.1 Août 2026

  • Correction Affichage Footer : Résolution du bug de dimensionnement massif et de superposition des logos vectoriels de la communauté Open Source dans le pied de page.

Version 1.2.0 Août 2026

  • Nouveauté Calculateur Carbone (Scope 3) : L'application calcule désormais les émissions de CO2 estimées en se basant sur le code NAF (ratio monétaire) et sur le calcul Fret (Tonne-Kilomètre).
  • Nouveauté Import enrichi : Le fichier CSV peut désormais contenir 3 colonnes (Nom, Montant en euros, Poids en kg) pour affiner les calculs.
  • Nouveauté Détection RSE : Identification automatique des structures de l'ESS (Économie Sociale et Solidaire) et des Sociétés à mission via les API.
  • Nouveauté Tableau de Bord : Création de l'onglet "Statistiques RSE" incluant une cartographie mondiale des partenaires et des graphiques interactifs (Chart.js).
  • Optimisation Refonte du tableau Validées : Regroupement des indicateurs (Alimentaire, ESS, Mission) dans une colonne unifiée "Labels RSE".

Version 1.1.1 Août 2026

  • Optimisation Indicateur de Santé : Déplacement du badge de statut juridique (Actif/Fermé...) directement à côté du nom de l'entreprise.
  • Nouveauté Sauvegarde SQL : Export complet de la base de données (structure et données).
  • Nouveauté Restauration SQL : Import direct d'un fichier dump (.sql) généré par l'application.
